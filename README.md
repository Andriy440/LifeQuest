# LifeQuest

**LifeQuest** — мобільний додаток для Android, який допомагає перетворити повсякденні справи та цілі на захопливу гру.

## 📥 Як завантажити та встановити

1. Перейдіть у розділ **[Releases](../../releases)** (або натисніть на останній реліз у меню праворуч).
2. Завантажте файл **`LifeQuest.apk`** на свій смартфон.
3. Відкрийте завантажений файл та підтвердьте встановлення. 
   *(Якщо система попросить дозвіл на встановлення з невідомих джерел — дозвольте його в налаштуваннях браузера або файлового менеджера).*

## 📱 Системні вимоги
* **ОС:** Android 8.0 або новіше.
